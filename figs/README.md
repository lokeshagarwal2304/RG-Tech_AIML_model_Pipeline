## 📸 Overview of Visual Assets
This directory stores visual assets, confusion matrices, and morphological inspection samples for GrainSight AI:
- **Cohen's Kappa Inter-Observer Matrices:** Agreement matrices across Rice, Wheat, and Sorghum inspection trials (`R1_wheat_*.png`).
- **Defect Morphology Gallery:** Sample optical images across all 8 condition classes:
  - `0_NOR`: Sound / Normal kernel (Golden / clean pericarp)
  - `1_FS`: Fusarium Head Blight / Scab (Paler, chalky lesions with vomitoxin risk)
  - `2_SD`: Sprouted kernel (Emergent radicle growth)
  - `3_MY`: Moldy kernel (Dark fungal mycelium cluster)
  - `4_AP`: Insect pest borehole (Attacked pericarp)
  - `5_BN`: Mechanically fractured / broken kernel
  - `6_UN`: Unripe / immature chalky grain
  - `7_IM`: Organic impurities / foreign chaff
- **XAI Heatmaps & Masks:** Embedded in `reports/` and `reports/figures/` for the official 12-page project report and 16:9 presentation deck.
